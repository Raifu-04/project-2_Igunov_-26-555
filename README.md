## Управление таблицами

База данных поддерживает следующие команды для работы со структурой таблиц:

* `create <имя_таблицы> <столбец1>:<тип> <столбец2>:<тип> ...`
  Создает новую таблицу. Доступные типы данных: `int`, `str`, `bool`. Поле `ID:int` добавляется автоматически.

* `drop <имя_таблицы>`
  Удаляет таблицу и все её данные.

* `help` — Показать меню с командами.
* `exit` — Выйти из программы.
